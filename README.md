# REDZONE Gaming 🎮

Welcome to REDZONE Gaming!

A gaming website project built with Node.js.

## Features
- Gaming website frontend
- Node.js backend
- Admin panel
- Database support
- File uploads

## Setup
1. Install Node.js.
2. Run `npm install`.
3. Configure your environment variables using `.env.example`.
4. Run `npm start`.

## Admin
Use the project's admin setup instructions to configure your administrator account securely.
