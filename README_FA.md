# REDZONE Gaming — راهنمای نصب فارسی

پروژه‌ی وب گیمینگ دو‌زبانه (فارسی/انگلیسی) با تم مشکی و قرمز، بک‌اند Node.js، دیتابیس SQLite و پنل ادمین.

## امکانات
- صفحه عمومی واکنش‌گرا با بخش‌های اخبار، بازی‌ها، دانلودها و مقالات
- تغییر زبان فارسی/انگلیسی
- پنل ادمین با ورود رمزنگاری‌شده
- افزودن، ویرایش، حذف و پیش‌نویس کردن محتوا
- آپلود تصویر
- دیتابیس محلی SQLite؛ نیازمند نصب جداگانه دیتابیس نیست
- محدودیت تلاش ورود، کوکی HttpOnly/SameSite، Helmet و هش رمز عبور

## پیش‌نیاز
Node.js نسخه 20 یا جدیدتر. نسخه را بررسی کن:
```bash
node -v
npm -v
```
دانلود Node.js: https://nodejs.org/

## نصب روی ویندوز
1. فایل ZIP را Extract کن.
2. در پوشه‌ی `redzone-gaming` پنجره‌ی CMD یا PowerShell باز کن.
3. وابستگی‌ها را نصب کن:
   ```bash
   npm install
   ```
4. فایل تنظیمات بساز:
   - PowerShell: `Copy-Item .env.example .env`
   - CMD: `copy .env.example .env`
5. فایل `.env` را باز کن و `SESSION_SECRET` را با یک مقدار تصادفی طولانی جایگزین کن. این مقدار را با کسی به اشتراک نگذار.
6. اکانت ادمین اصلی را بساز:
   ```bash
   npm run create-admin
   ```
   نام کاربری و رمز عبور قوی وارد کن. رمز باید حداقل ۱۲ کاراکتر باشد. ابزار نصب، رمز را به صورت hash ذخیره می‌کند.
7. سایت را اجرا کن:
   ```bash
   npm start
   ```
8. آدرس‌ها:
   - سایت: http://localhost:3000
   - پنل ادمین: http://localhost:3000/admin/login

برای اجرای توسعه:
```bash
npm run dev
```

## استفاده از پنل
- وارد پنل شو.
- نوع محتوا را News، Game، Download یا Article انتخاب کن.
- برای نمایش درست در هر دو زبان، عنوان فارسی و انگلیسی را وارد کن.
- برای دانلودها، لینک رسمی/مجاز را در Link URL قرار بده.
- برای تصویر می‌توانی URL تصویر بدهی یا تصویر را آپلود کنی.
- گزینه Published را بردار تا محتوا ذخیره شود ولی در سایت عمومی نمایش داده نشود.
- از Edit برای ویرایش و Delete برای حذف استفاده کن.

## امنیت مهم
- اکانت ادمین را با `npm run create-admin` ایجاد کن؛ هیچ رمز پیش‌فرضی در پروژه وجود ندارد.
- `.env` و پوشه `data/` را منتشر نکن. `.env` حاوی کلید نشست و `data/redzone.db` شامل کاربران و محتواست.
- پیش از انتشار عمومی، `NODE_ENV=production` بگذار، `SESSION_SECRET` تصادفی حداقل ۳۲ کاراکتری تنظیم کن و سایت را پشت HTTPS اجرا کن.
- برای سایت عمومی، از یک reverse proxy مانند Nginx/Caddy با HTTPS استفاده کن؛ در حالت production کوکی نشست secure است.
- از دیتابیس و پوشه `uploads/` بکاپ منظم بگیر.
- این پروژه پایه‌ی قابل اجراست؛ پیش از استفاده‌ی تجاری گسترده، تست امنیتی، مانیتورینگ، بکاپ و سیاست حریم خصوصی را اضافه کن.
- فقط فایل‌هایی را لینک کن که حق توزیع‌شان را داری. بهتر است دانلودها به صفحه رسمی سازنده لینک شوند.

## رفع خطاهای معمول
- `node` شناخته نشد: Node.js را نصب کن و ترمینال را دوباره باز کن.
- نصب `better-sqlite3` خطا داد: از Node.js نسخه 20 یا جدیدتر استفاده کن و `npm install` را دوباره اجرا کن.
- ادمین وارد نمی‌شود: مطمئن شو `npm run create-admin` موفق شده و زبان کیبورد/حروف رمز درست است.
- پورت 3000 اشغال است: در `.env` مقدار `PORT=3001` بگذار و دوباره اجرا کن.
- سایت از گوشی باز نمی‌شود: کامپیوتر و گوشی باید در یک شبکه باشند؛ از IP محلی کامپیوتر به همراه پورت استفاده کن و فقط در شبکه‌ی قابل اعتماد فایروال را تنظیم کن.
